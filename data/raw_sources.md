# Источники данных

## 1. Загрязнение поверхностных вод в России  
*Ежемесячные данные о высоком и экстремально высоком загрязнении водных объектов, 2008 – 2021 гг.*

| Пункт | Детали |
|-------|--------|
| Официальная страница | <https://data.rcsi.science/data-catalog/datasets/176/#dataset-codebook> |
| Поставщик данных | Росгидромет |
| Периодичность | ежемесячно (данные 2008-01 — 2021-08) |
| Формат опубликования | DOCX-отчёты, сконвертированные авторами датасета в CSV (UTF-8, `;`) |
| Лицензия | **CC BY-SA** |
| Общий объём наблюдений | 18 081 |
| Дата публикации | 23 сентября 2021 |
| Обновления | не указано |

### Файлы

| Имя файла | Тип | Строк | Атрибутов | Краткое содержание |
|-----------|-----|-------|-----------|--------------------|
| `extreme_pollution.csv` | основная таблица | **7 671** | 13 | Экстремально высокие загрязнения (до уровня муниципалитета). |
| `high_pollution.csv` | основная таблица | **10 198** | 11 | Высокие загрязнения (уровень субъекта РФ). |
| `pdk.csv` | справочник | **212** | 10 | Предельно допустимые концентрации (ПДК) для веществ. |

### Краткое описание полей

<details>
<summary>Экстремально высокое загрязнение (extreme_pollution)</summary>

| Поле | Описание |
|------|----------|
| `id` | Уникальный идентификатор записи |
| `period` | Последний день отчётного месяца |
| `subject` | Субъект РФ |
| `municipality`, `settlement`, `oktmo` | Детализация места |
| `water_body` | Водоём, где зафиксировано загрязнение |
| `indicator` | Название загрязняющего вещества / показателя |
| `hazard_class` | Класс опасности вещества (1 – 4, 4Э) |
| `cnt_cases` | Число случаев в отчётный период |
| `value_min`, `value_max`, `unit` | Диапазон измеренных концентраций и единица измерения |
</details>

<details>
<summary>Высокое загрязнение (high_pollution)</summary>

Отличается отсутствием детальных координат (`municipality`, `settlement`) и наличием поля `river_basin` (бассейн крупной реки).
</details>

<details>
<summary>Справочник ПДК (pdk)</summary>

| Поле | Описание |
|------|----------|
| `ingredient` | Нормализованное название вещества |
| `value` | ПДК (числовое значение) |
| `lpv` | Лимитирующий показатель вредности |
| `hazard_class` | Класс опасности |
| + вспомогательные поля (формула, CAS, НПА) |
</details>

### Преобразование в проекте

1. **Сырые CSV** → каталог `data/raw/`.  
2. С помощью `clean_water_pollution.py` выполняется 🧹 очистка и сохранение в Parquet (`data/clean/`).  
3. Аналитические скрипты (`analysis_*`, `analyse_geography.py`) формируют агрегаты → `data/analysed_data/`.  
4. Визуализация — Power BI (Web) через выгрузку агрегатов в CSV или прямое подключение к БД.
