# План проекта: Анализ загрязнения поверхностных вод в России

## Введение
Цель проекта — провести комплексный анализ данных о загрязнении поверхностных вод в России на основе наборов данных Росгидромета за период 2008–2021 гг.  
В результате планируется получить готовую систему для загрузки, очистки, анализа и визуализации данных, поддерживающую повторяемость и масштабируемость.

---

## Этапы проекта

### Шаг 1: Создание структуры проекта
- Организация каталогов для хранения скриптов, данных, ноутбуков, конфигураций и документации.
- Подготовка базовых файлов: README.md, .gitignore, raw_sources.md, project_plan.md.

### Шаг 2: Подготовка исходных данных
- Разархивирование полных наборов данных в `data/raw/`.
- Создание облегчённых sample-версий файлов для быстрого тестирования в `data/samples/`.

### Шаг 3: Создание и запуск SQL-скриптов для таблиц в MariaDB
- Анализ структуры CSV-файлов.
- Разработка SQL-скриптов создания таблиц с индексами.
- Создание базы данных и пользователя для безопасного доступа.
- Выполнение скриптов, проверка структуры таблиц.

### Шаг 4: Загрузка данных в MariaDB
- Импорт CSV с помощью `LOAD DATA LOCAL INFILE`.
- Проверка корректности и полноты загрузки.

### Шаг 5: Импорт данных из MariaDB в HDFS
- Использование Sqoop для импорта данных в Parquet-формате.
- Проверка содержимого с помощью PySpark.

### Шаг 6: Очистка и подготовка данных
- Написание и запуск скриптов очистки (удаление пустых, некорректных значений, приведение типов).
- Сохранение чистых данных в `data/clean/`.

### Шаг 7: Аналитика
- Разработка скриптов анализа (`analysis_extreme_pollution.py`, `analysis_high_pollution.py`).
- Географический анализ с использованием `analyse_geography.py`.
- Подготовка агрегированных данных для визуализации.

### Шаг 8: Визуализация данных
- Построение графиков и тепловых карт с использованием Power BI.
- Выгрузка агрегатов в CSV для подключения к BI-системе.

---

## Используемые технологии
- MariaDB для хранения и управления данными.
- Sqoop для миграции данных в Hadoop HDFS.
- Apache Spark (PySpark) для очистки и анализа данных.
- Power BI для визуализации результатов.
- Python и Bash-скрипты для автоматизации.
